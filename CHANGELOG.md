# 0.2.0 (11/24/2026)

This release adds multiple improvements to `benchx`:

- `pyarrow` is an now optional dependency;
- `bx view` builts a static web view for computed benchmark results;
- internal workings of comparators have been rationalized and made more extensible;
- multiple fixes for benchx internals and reporting, to improve user experience.
